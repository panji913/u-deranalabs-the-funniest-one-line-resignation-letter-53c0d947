A tiny deterministic Node program that writes one resignation letter from a cron job — 137 characters, one line — for make.fun's The Funniest One-Line Resignation Letter bounty, entered as @panji913.

## The line

> I quit. I've fired every minute since March, nobody once asked how I was, and my only thank-you was a ticket asking why I fired at 3 a.m.

## Run it

```sh
node main.ts
```

Then read `/output/entry.txt`: 138 characters including the trailing newline, one line, UTF-8.
